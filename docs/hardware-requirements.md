# 動作要件

| 項目 | 構築・導入の条件 |
| --- | --- |
| OS | x64 Windows 10 22H2以降 / Windows 11 |
| Rust | Rust/Cargo 1.89以上のMSVC toolchain、C++ Build Tools、Windows SDK |
| アプリ用Python | 3.11〜3.13。ComfyUI用Pythonと分離 |
| 推論用GPU | NVIDIA Ampere以降、compute capability 8.0以上。新規CUDA 13.0構成はR580以降のドライバー |
| VRAM | 導入判定は12GB以上。24GB以上を推奨するが、12GB / 16GBの実H3完走は未確認 |
| RAM | 導入判定32GB以上、64GB推奨 |
| 空き容量 | 新規全量導入の目安120GB以上。cache・モデル配置先・素材・中間・出力を別に見積もる |
| ストレージ | モデル配置先はhard linkに対応すること。完成出力の保存先に書き込めること。NTFS推奨 |
| ネットワーク | 明示したコード・依存・モデル取得で公式配布元へ接続可能なこと |

これは導入判定です。実動画の完走・速度・画質を保証しません。現行LoRA付き構成はRTX 4090 24GBで短い合成動画の実H3を確認していますが、物理12GB / 16GB、長尺、別PCの全量導入から生成までの通し確認は別に必要です。

VRAM、PCのRAM、モデルファイルの容量は別の値です。24GB GPUで予約やCPU退避を設定しても、物理12GB / 16GB機の確認にはなりません。導入先の実際の空きメモリと他プロセスも考慮してください。[導入案内](model-setup.md)を参照してください。
