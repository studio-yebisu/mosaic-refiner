# ソース提供の範囲

このリポジトリは、AIによる読取り・ローカル導入補助を想定したソースデモです。コードと必要な導入・条件文書だけを提供し、過去のprivate履歴を引き継ぎません。動画、モデル、テスト用ファイル、内部レビュー・検証記録、認証情報、環境ログ、job、cache、構築済みbinaryは公開対象外です。

独自部分はAGPL-3.0-only、第三者表示と本文は維持します。主LoRA一つと本人のCivitai API認証は必須です。利用条件を明示確認して固定版を取得し、ファイルの照合後にH3で補正します。許諾調査を理由とする一律停止は設けません。

構築・環境診断・画面起動の確認と、モデルの許可・実H3・画質・低VRAM・長尺の検証は別です。正式installer / GitHub Releaseや、すべてのPCで動く完成品としての提供ではありません。[AI導入案内](ai-setup.md)、[実装状況](implementation-plan.md)、[必須LoRA](required-lora.md)を確認してください。
