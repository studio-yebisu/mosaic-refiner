# 実装状況と残件

| 項目 | 状態 |
| --- | --- |
| ソース提供 | AIによる読取り・導入補助を想定。コードと必要文書を提供 |
| アプリ | Rust host / core、Python worker、Web画面、セットアップ、保存と再開の経路を実装 |
| 必須LoRA | 一つの選択・正の強度・両H3段への配線・本人Civitai認証を実装 |
| モデル実行 | 両LoRAとH3条件の整合が確認待ちのため、導入・自動取得・H3推論を停止 |
| 実モデル検証 | 現行LoRA付き構成の実H3・画質・12GB / 16GB・長尺・別PC全量導入は未確認 |
| 配布物 | 重み・動画・内部検証記録・テスト用ファイル・旧Git履歴・exe / DLLを非同梱。正式installer / Releaseは未提供 |

今後は権利者の条件を確かめ、必要な表示と安全措置を反映したprofileを確定してから、権限のある合成素材でLoRA適用、両生成段、数値保全、時間・メモリを確認します。実素材の画質は別にレビューします。

コードの公開はモデル用途の許可や実測の代わりではありません。停止を解除して既成事実を作ったり、別モデルへ代用したりしません。[必須LoRA](required-lora.md)と[利用条件](use-conditions.md)を確認してください。
