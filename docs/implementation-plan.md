# 実装状況と残件

| 項目 | 状態 |
| --- | --- |
| ソース提供 | AIによる読取り・導入補助を想定。コードと必要文書を提供 |
| アプリ | Rust host / core、Python worker、Web画面、セットアップ、保存と再開の経路を実装 |
| 必須LoRA | 一つの選択・正の強度・両H3段への配線・本人Civitai認証を実装 |
| モデル実行 | 本人認証と利用条件の明示確認で固定版を取得し、必要ファイルの照合後に動画補正を実行 |
| 実モデル検証 | 両LoRAをそれぞれ使う短い合成動画で、実H3・保存・対象外画素・時刻・音声を確認。実素材の一般的な画質、12GB / 16GB、長尺、別PC全量導入は別に確認 |
| 配布物 | 重み・動画・内部検証記録・テスト用ファイル・旧Git履歴・exe / DLLを非同梱。正式installer / Releaseは未提供 |

今後も配布元の条件と表示を確認し、権限のある素材で数値保全、時間・メモリ、画質をそれぞれ確認します。短い合成動画の検査を、すべての実素材や低VRAM機での確認には転用しません。

コードの公開や認証成功は、モデル用途の許可そのものではありません。主LoRAと本人認証を必須に保ち、利用者が[モデルの条件](required-lora.md)と[利用条件](use-conditions.md)を確認して使う構成です。
