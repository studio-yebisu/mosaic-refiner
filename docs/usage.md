# 利用ガイド

[必須LoRA](required-lora.md)と各モデルを準備し、ローカル画面で動画を選んで「補正を開始」を押します。不足モデルの取得には本人のCivitai API認証と利用条件の確認が必要です。実行時のファイル照合で不足・不一致があれば、理由を表示して停止します。

`start-web.cmd`でローカル画面、`start-setup.cmd`で導入設定を開きます。起動スクリプトが開いたURLを使い、操作キー付きURLを共有しません。アプリの操作サーバーはComfyUIのAPIとは別です。

動画のドロップ・選択はローカルの入力控えを作り、絶対パス指定は原本を読み取ります。入力控えと記録は通常`%LOCALAPPDATA%/MosaicRefiner/web`以下に置きます。完成動画は入力先と同じ場所へ別名保存し、既存ファイルを上書きしません。

プレビューは明示操作時だけ生成・表示します。開始は新しいジョブ、再開は保存した条件を使います。別の条件で比べる場合は新しく開始し、旧profileの未完成ジョブを現行モデルへ自動変換しません。

ブラウザーを閉じても処理の取消しにはなりません。取消しは自分の生成窓が安全に保存されるまで待ち、共有ComfyUIの全ジョブをinterruptしません。「アプリを終了」で操作サーバーを終了できます。

完成後の中間素材は自動削除しません。「途中素材を削除」は検査と所有確認を通した範囲だけを削除し、原本・入力控え・完成動画・記録は保持します。削除は復元不能な操作として対象を確認してください。
