# セキュリティ上の注意

このプロジェクトは保守対象外です。継続的な脆弱性監査・更新・修正・サポートや、不具合・脆弱性報告の受付は行いません。[セキュリティ方針](../SECURITY.md)を確認してください。以下は公開時点の実装上の対策と、利用時の注意です。

操作サーバーはloopbackへ限定し、Host・操作token・Originと外部frame埋込みを検査します。起動スクリプトが開く操作URLは秘密として扱います。インターネットへ公開する設定で運用しないでください。

ComfyUIのHTTP・WebSocket通信はシステムのプロキシを経由させません。HTTPのredirectも追跡しません。推論workerには通常の時間制限を設けず、取消しは安全な保存点で行います。Windowsではアプリが強制終了されたときに自身のworkerと子processを回収し、別起動の共有ComfyUIは終了しません。

取得は公式配布元、固定版とSHA、URL / redirect制限、本人入力の認証、同名ファイルの上書き拒否を使います。コード・wheel・モデルを起動の副作用で取得しません。本人のキーはチャット・引数・URL・通常設定・ログ・Gitへ渡しません。OS保存は本人の明示選択で行います。

素材・モデル・ジョブ・ログ・cacheは公開対象外です。出力保存と整理は所有確認を行い、原本・既存出力を保全します。別途導入したComfyUIノードや他アプリの通信・安全性まで管理する機能ではありません。

これらの実装は全脆弱性の不在を保証しません。必要な検証や更新は、ご自身の環境やfork先で行ってください。元動画、生成動画、人物情報、job、未加工ログ、APIキー、操作キー付きURLを公開しないでください。
