# セキュリティと報告

操作サーバーはloopbackへ限定し、Host・操作token・Originと外部frame埋込みを検査します。起動スクリプトが開く操作URLは秘密として扱います。インターネットへ公開する設定で運用しないでください。

取得は公式配布元、固定版とSHA、URL / redirect制限、本人入力の認証、同名ファイルの上書き拒否を使います。コード・wheel・モデルを起動の副作用で取得しません。本人のキーはチャット・引数・URL・通常設定・ログ・Gitへ渡しません。OS保存は本人の明示選択で行います。

素材・モデル・ジョブ・ログ・cacheは公開対象外です。出力保存と整理は所有確認を行い、原本・既存出力を保全します。別途導入したComfyUIノードや他アプリの通信・安全性まで管理する機能ではありません。

これらの実装は全脆弱性の不在を保証しません。不具合は秘密を除いた再現手順、OS・GPU・版、最小限のエラーで報告してください。公開Issueへ元動画、生成動画、人物情報、job、未加工ログ、APIキー、操作キー付きURLを添付しないでください。秘密が必要な調査は公開Issueの外で適切な窓口を確認してから行います。
