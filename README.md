# MosaicRefiner

動画のモザイク領域を検出・追跡し、生成AIで補正するWindows向けローカルアプリのソースです。AIが補う内容は推測であり、失われた元情報の復元や元の人物・出来事との一致を保証しません。

**0.1.0 / AIアシスタントによる導入補助を想定した技術検証デモ。** コードと必要な導入・ライセンス文書を提供します。重み、動画、テスト用ファイル、検証記録、過去の開発履歴、構築済みexe / DLLは含みません。

**現在、必須LoRAの許諾とH3条件との整合は確認待ちで、モデル導入・自動取得・H3推論は停止しています。** ソースを読んで構築・環境調査・起動確認を進めることと、実モデルで動画を補正することを区別してください。[必須LoRAと残件](docs/required-lora.md)を参照してください。

## AIに読ませる

ローカルPCを操作できるAIへ、このリポジトリのURLと次の依頼文を渡してください。チャットのみのAIには手順の案内を頼めます。

```text
https://github.com/studio-yebisu/mosaic-refiner を読み、私のローカルPCでの
構築・導入診断・起動確認を手伝ってください。
README.md、AGENTS.md、docs/ai-setup.mdから読み、導入先PCの環境を確認してください。
既存のComfyUIと作業中のデータを保全し、開発者の固定パスを転用しないでください。
主LoRA一つと本人のCivitai API認証は必須です。
本人のキーはチャットで受け取らず、セットアップ画面か本人の対話端末へ案内してください。
許諾確認待ちの取得・推論停止を解除せず、実行できた範囲と残件を分けて報告してください。
```

[AI導入案内](docs/ai-setup.md)に読む順番、確認項目、進められる範囲をまとめています。

## 実装している機能

- 動画の選択・ドロップ・ローカルパス入力、自動検出・追跡と手動領域指定。
- BasicVSR++ → H3低段 → latentの縦横2倍補間 → H3高段の処理。
- 進捗、取消し、条件を保存した中断再開、処理履歴。
- 元の時刻・音声・対象外画素の数値検査と、原本・既存出力を上書きしない保存。

実装済みの処理経路の一覧です。現行LoRA構成は上記の停止中で、実H3・画質・低VRAM対応を確認済みとはしていません。詳細は[設計](docs/design.md)と[実装状況](docs/implementation-plan.md)へ記載しています。

## 構築と導入

Windows x64、Rust/Cargo 1.89以上のMSVC toolchain、C++ Build ToolsとWindows SDKを用意します。推論環境の導入判定はNVIDIA Ampere以降・VRAM 12GB以上・RAM 32GB以上です。VRAM 24GB、RAM 64GB、空き120GB以上を推奨しますが、**12GB / 16GBの実H3完走は未確認**です。[動作要件](docs/hardware-requirements.md)を確認してください。

1. このリポジトリをcloneまたはZIPから展開します。
2. `setup-app.cmd`を実行するとアプリ用Python・依存を準備し、推論環境のセットアップ画面を開きます。アプリの準備にはネットワーク接続を使います。
3. 既存ComfyUIの場所・Python・APIを選びます。PC要件・導入計画・条件を確認できます。全体導入はLoRAの許諾確認待ちで停止します。
4. アプリのフォルダーで明示的にRustを構築します。

```powershell
./.venv/Scripts/python.exe -B scripts/build_native.py
./.venv/Scripts/python.exe -B -m mosaic_refiner --help
```

5. `start-web.cmd`でローカル画面を開きます。`start-gui.cmd`も同じ画面です。`start-setup.cmd`で導入設定を確認できます。

既存の推論環境を自動更新しません。新規環境の計画は最新の互換安定ソフトウェアを解決し、中断後は記録した版・hashで再開します。モデルは固定版を使います。詳しくは[モデル準備](docs/model-setup.md)を参照してください。起動だけでモデルを取得したりAI生成を始めたりしません。

## 本人認証とデータ

**主LoRAはUnlocked V2 / DecensoreH3の一つ、取得には本人のCivitai APIキーが必須**です。Hugging Faceの読取り用tokenは必要な場合だけ使います。本人がセットアップ画面に非表示入力し、メモリのみで使うかWindows資格情報マネージャーへ保存するかを選びます。キーをチャット、CLI引数、URL、環境変数、通常設定、ログ、Gitへ貼り付けないでください。

本人認証や条件確認のチェックだけで許諾済みにはなりません。匿名取得・別LoRA・mirrorへの代用、自動購入は行いません。

動画処理はお使いのローカルPCで行います。モデル・依存の導入時は配布元へ接続します。アプリに動画をクラウド推論へ送る機能はありません。利用者が別途導入したノードや他アプリの通信は管理対象外です。

起動スクリプトが開く操作URLには操作キーが含まれるため、共有しないでください。原本・入力控え・既存出力は保全します。操作と保存先は[利用ガイド](docs/usage.md)を参照してください。
