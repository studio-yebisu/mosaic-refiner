# MosaicRefiner

作成: [StudioYebisu](https://github.com/yebisu0529-ship-it)

動画のモザイク領域を検出・追跡し、生成AIで補正するWindows向けローカルアプリのソースです。補正結果はAIによる推測であり、失われた元情報の復元や、元の人物・出来事との一致を保証しません。

**バージョン0.1.0の技術検証デモ**で、AIアシスタントによる導入補助も想定しています。公開物はソースと必要な文書だけです。モデルの重み、動画、テスト用ファイル、内部検証記録、旧Git履歴、構築済みのexe / DLLは同梱していません。

**このプロジェクトは保守対象外です。** 継続的な保守・脆弱性監査・修正・導入サポートは行いません。IssueとPull requestは受け付けません。必要な検証や変更は、ご自身の環境やfork先で行ってください。[変更の方針](CONTRIBUTING.md)と[セキュリティ方針](SECURITY.md)を確認してください。

## 動画を補正する

主LoRAはUnlocked V2 / DecensoreH3の一つが必須です。不足モデルの取得には、本人のCivitai APIキーと配布元の利用条件の確認が必要です。

1. 以下の手順でアプリを準備します。セットアップ画面で主LoRAを一つ選び、本人のCivitai APIキーを入力します。導入計画と利用条件を確認し、「すべて導入 / 再開」で必要なモデルとノードを導入します。
2. `start-web.cmd`で画面を開き、動画を選びます。自動検出か手動指定で、補正する領域を決めます。
3. 「補正を開始」を押します。完了後は、別名で保存した動画を確認できます。元動画は上書きしません。

取得時は本人認証と固定版のmetadata、実行時はモデルとLoRAの容量・SHAを照合します。不足・不一致がある場合は理由を表示して停止し、LoRAの省略や別モデルへの自動代用は行いません。[必須LoRAと利用条件](docs/required-lora.md)を確認してください。

## 実装している機能

コードには次の機能を実装しています。

- 動画の選択・ドロップ・ローカルパス入力
- モザイクの自動検出・追跡と手動領域指定
- BasicVSR++ → H3低段 → latentの縦横2倍補間 → H3高段の順に行う補正処理
- 進捗表示、取消し、条件を保存した中断再開、処理履歴
- 元の時刻・音声・対象外画素の数値検査
- 原本・入力控え・既存出力を上書きしない保存

短い合成動画で両LoRAをそれぞれ使い、H3による補正から保存までの動作を確認しています。実素材の一般的な画質、物理12GB / 16GB VRAM、長尺動画は別に確認する必要があります。詳しくは[設計](docs/design.md)と[実装状況](docs/implementation-plan.md)を参照してください。

## 準備するもの

| 項目 | 構築・導入の条件 |
| --- | --- |
| OS | x64 Windows 10 22H2以降 / Windows 11 |
| 構築ツール | Rust/Cargo 1.89以上のMSVC toolchain、C++ Build Tools、Windows SDK |
| アプリ用Python | 3.11〜3.13。ComfyUI用Pythonとは別に用意 |
| 推論用GPU | NVIDIA Ampere以降、compute capability 8.0以上 |
| VRAM / RAM | 導入判定はVRAM 12GB以上、RAM 32GB以上。VRAM 24GB、RAM 64GBを推奨 |
| 空き容量 | 新規全量導入の目安は120GB以上。素材・中間データ・完成動画の分は別途見積もり |

GPUやメモリの数値は導入計画の判定条件で、実動画の完走・速度・画質を示すものではありません。詳細は[動作要件](docs/hardware-requirements.md)を確認してください。

## 構築と起動

1. リポジトリをcloneするか、ZIPを展開します。
2. `setup-app.cmd`を実行します。アプリ用Pythonと依存を準備し、推論環境の設定画面を開きます。この準備にはネットワーク接続を使います。
3. 設定画面で使うComfyUIを一つ選び、その場所・Python・ローカル接続用のAPIアドレスを指定します。主LoRAの選択・本人のキー入力・条件確認を済ませ、「すべて導入 / 再開」を実行します。既存環境の起動・再起動を案内された場合は普段の方法で起動し、同じ画面で導入を再開してください。詳しい操作は[セットアップ画面から補正まで](docs/model-setup.md#セットアップ画面から補正まで)を参照してください。
4. アプリのフォルダーで、Rustを明示的に構築してCLIを確認します。

```powershell
./.venv/Scripts/python.exe -B scripts/build_native.py
./.venv/Scripts/python.exe -B -m mosaic_refiner --help
```

5. 導入完了後にセットアップ画面を閉じ、`start-web.cmd`でローカル画面を開きます。既存ComfyUIは先に普段の方法で起動してください。新規導入したComfyUIはアプリが起動します。新しく選んだ動画には、導入時に選んだ主LoRAが設定されます。`start-gui.cmd`も同じ画面です。導入設定を確認する場合は`start-setup.cmd`を使います。

起動だけで大容量モデルを取得したり、AI生成を始めたりすることはありません。モデルは本人認証と利用条件の確認を通して取得します。新規ComfyUIは公式の最新安定release、必要ノードは配布元の現行commit、依存は互換性のある安定版を選びます。中断後は記録した版とhashを使って再開します。モデルは固定バージョンを使います。詳細は[構築とモデル準備](docs/model-setup.md)を参照してください。

## 必須LoRAと本人認証

主LoRAは、**MiniMax H3 Unlocked V2またはDecensoreH3のいずれか一つが必須**です。二つを重ねず、LoRAなし、強度0、別モデルへの自動代用は行いません。実際の取得には本人のCivitai APIキーも必要です。Hugging Faceの読取り用tokenは、必要な場合だけ使います。

キーは本人がセットアップ画面の非表示欄、または本人の対話端末へ入力します。メモリ内だけで使うか、Windows資格情報マネージャーへ保存するかを本人が選べます。AIのチャット、CLI引数、URL、環境変数、通常設定、ログ、Gitへ渡さないでください。匿名取得やmirrorへの置き換えも行いません。

## AIに導入補助を頼む

ローカルPCを操作できるAIには、リポジトリのURLと次の依頼文を渡せます。チャットのみのAIには、手順の案内を頼んでください。

```text
https://github.com/studio-yebisu/mosaic-refiner を読み、私のローカルPCでの
構築・導入診断・起動確認を手伝ってください。
README.md、AGENTS.md、docs/ai-setup.mdから読み、導入先PCの環境を確認してください。
既存のComfyUIと作業中のデータを保全し、開発者の固定パスを転用しないでください。
主LoRA一つと本人のCivitai API認証は必須です。
本人のキーはチャットで受け取らず、セットアップ画面か本人の対話端末へ案内してください。
必須LoRA・本人認証・固定ファイルの検査を保ち、動画補正と保存まで確認してください。
```

確認項目と進められる範囲は[AI導入案内](docs/ai-setup.md)にまとめています。
